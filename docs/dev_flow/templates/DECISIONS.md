# Decisions

Use this file with Scribe capture to preserve owner decisions, agent decisions,
reversals, and the evidence that made the decision safe. Keep implementation
status in `STATE.md`; keep user steering and corrections in `OPERATOR_NOTES.md`.

## Owner Decisions
- <YYYY-MM-DD HH:MM TZ> - <decision> - Impact: <impact> - Evidence: <artifact/command/user instruction>

## Agent Decisions
- <YYYY-MM-DD HH:MM TZ> - <decision> - Evidence: <evidence> - Risk: <accepted risk or none>

## Reversed Or Superseded Decisions
- <YYYY-MM-DD HH:MM TZ or None> - <old decision> - Replacement: <new decision> - Reason: <why it changed>

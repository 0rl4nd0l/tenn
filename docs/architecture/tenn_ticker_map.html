Tenn Ticker Map

This view renders one company as an actual data map, not just a generic architecture sketch. It reads the backend-authoritative /api/context/company_dump bundle and shows the live surfaces connected to a ticker: financial rows, filings, risk notes, price context, extraction failures, and memory layers.

Load a company bundle

The page stays inside the client layer. It does not talk to Postgres, Qdrant, or local files directly. It only reads the existing backend context endpoint.

Recommended server: python scripts/serve_docs_proxy.py --port 8766. That serves the HTML and proxies /api/* through the same origin, so the ticker map works from one forwarded port. If you use python -m http.server instead, browser fetches to a separate backend port can be blocked by cross-origin policy.

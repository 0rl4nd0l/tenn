# Skills Inventory

Status values:

- `CORE_KEEP`: visible or central Tenn workflow.
- `BACKEND_KEEP`: keep, but call from wrappers or guards.
- `MERGE_INTO_WRAPPER`: fold into a smaller operator-facing command.
- `RENAME_OR_REHOME`: keep the idea, move or rename later.
- `DEPRECATE`: stop presenting as active day-to-day workflow.
- `DELETE_CANDIDATE`: candidate for later deletion after owner review.
- `OWNER_BOUNDARY`: plugin, host-global, destructive, credentialed, or
  domain-specialty surface that should not be Tenn-default.
- `UNKNOWN_NEEDS_OWNER_DECISION`: evidence insufficient or ownership unclear.

## Plugin-Owned Specialty Skills

macOS, web apps, web data visualization, security, GitHub, Google Drive,
OpenAI developer tooling, Hugging Face, investment banking, and public equity
investing bundles.

be part of Orlando's day-to-day Tenn command surface. Use their routers only
when the user explicitly asks for the plugin domain, for example GitHub PR
comment work, Google Drive files, Hugging Face jobs, iOS/macOS/web app work,
security scans, or investment/public-equity deliverables.

`OWNER_BOUNDARY` for Tenn dev-flow, `BACKEND_KEEP` inside their plugin domain.

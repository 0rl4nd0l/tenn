# Goal frame

## Product surface

Tenn Financial Truth ASX document classification, immutable observations,
profile projection, evidence-backed review, release evaluation, and bounded
operations.

## Invariants

- Source evidence is authoritative; model output is never canonical truth.
- Classification selects a contract but cannot prove metrics or authorize
  persistence.
- Sparse observations cannot erase earlier accepted values.
- Statutory and adjusted disclosures remain separate.
- Ambiguity abstains or quarantines.
- Protected corpus artifacts remain local and outside Git.
- Implementation, review, publication, merge, runtime proof, and activation
  are separate decisions.

## Completion model

Each ticket requires one fresh Codex X implementation, an exact frozen delta,
one fresh independent read-only Codex X review, parent acceptance, focused
validation, and a draft PR. Tickets with Tier 2 acceptance criteria additionally
require explicit owner approval and operational proof before they can close.

## Non-goals

No whole-program mega-patch, unbounded retry loop, protected holdout
publication, implicit extraction/evaluation, direct production mutation, or
automatic merge.
